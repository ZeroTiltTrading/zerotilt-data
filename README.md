# Zero Tilt – Live Track Record

Public live results of the Zero Tilt TradingView indicator (BTC, ETH, XRP) since November 1, 2026.

- `trades.json` is updated automatically once a day.
- Only closed trades are listed, published after the day has ended. Open trades are shown as a count only.
- Every winner and every loser stays in the file. The git history shows every change.
- Results are in R (multiples of the risk per trade). Times in CET (Central European Time, CEST in summer).

Website: https://zerotilt.ch · Not financial advice.
